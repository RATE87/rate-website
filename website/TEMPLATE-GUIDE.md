# RATE Website Template Guide

This site is set up to be edited as a content template rather than redesigned page by page.

## Main editable files

- `content.js`
- `index.html`
- `about.html`
- `toolkit.html`
- `community.html`
- `roadmap.html`
- `styles.css`

## Best place to edit first

Most text, labels, cards, and page sections now live in `content.js`.

Edit `styles.css` when you want to change:

- colors
- spacing
- card styles
- image sizing
- layout

## Reusable section patterns

- `page-head`
  Use for the top of a page. Keep this short: eyebrow, strong heading, one sentence, optional tags.

- `media-shell`
  Use for images, diagrams, logos, or mockups. This keeps visuals centered and scaled correctly.

- `chip-row`
  Use for short supporting points instead of another paragraph.

- `grid-3`
  Use for three concise cards.

- `grid-2`
  Use for two larger content blocks.

- `statement-band`
  Use for one strong sentence or quote to break up the page.

## Editing rule

If a section feels long, turn the extra copy into:

1. a chip
2. a card title
3. a short supporting sentence

That keeps the site visual and easier to scan.
