## Important Note

This pack is best treated as a prototype starter set.

Because the source art is one standing front pose, these animations are most suitable for:

- standing front-view exercises
- quick motion tests
- proof-of-concept review inside the app

For full professional production quality across all 97 exercises, the character should ideally also exist in:

- side view
- seated pose
- lying pose
- plank/prone pose
- hanging pose
- overhead-arm pose
